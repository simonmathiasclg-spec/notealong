# Listening samples, third round (second overnight run)

The first minute of six backing tracks before and after the band upgrade of Part 5, plus one new song.
Same song, same arrangement code otherwise; what changed is listed in `docs/NEXT_REPORT.md` (Part 5).

| File | Style | What to listen for |
|---|---|---|
| 1-swing-when-the-saints-go-marching-in | swing (brushes, 126 bpm) | the sampled grand piano comping; the bass "in two" through the first section, then walking; the band lifting in the last eight bars |
| 2-gospel-amazing-grace | gospel | sampled grand piano, a real drum kit (Virtuosity Drums) and a sampled electric bass instead of General MIDI sounds |
| 3-waltz-happy-birthday | waltz | the sampled grand piano's oom-pah-pah; a quieter first section |
| 4-ballad-shenandoah | ballad | the sampled grand piano's rolling left hand |
| 5-lullaby-brahms-lullaby | lullaby | soft arpeggios on the sampled grand |
| 6-gospel-down-by-the-riverside | gospel, up-tempo | the sampled kit's back-beat and tambourine with the electric bass walk-ups |
| 7-swing-sticks-sweet-georgia-brown-new | swing with sticks (184 bpm) | a new song: ride cymbal "ding, ding-a ding", hi-hat on two and four, snare comping, a crash where the bass starts walking |

The "before" files were cut from the tracks as they were at the start of this run; the "after" files
from the re-rendered tracks. All are 128 kbps MP3, 60 seconds with a 3-second fade.
