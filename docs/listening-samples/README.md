# Listening samples

I can measure audio but not hear it, so these are here for your ears. Everything below was rendered by
the code in this repository.

## New backing tracks (Part 4)

| File | Style | What to listen for |
|---|---|---|
| `1-waltz-happy-birthday.mp3` | waltz | oom-pah-pah piano, strings behind it, brushes; two-bar intro |
| `2-carol-in-6-8-silent-night.mp3` | carol, 6/8 | strings, harp arpeggios, soft choir, a bell every other bar, triangle |
| `3-swing-when-the-saints.mp3` | swing | walking bass, brushes with the ride pattern, piano comping, horn stabs under held notes |
| `4-gospel-swing-low-sweet-chariot.mp3` | gospel | piano pushes, organ pad, bass walk-ups, back-beat with tambourine, a fill every eight bars |
| `5-folk-waltzing-matilda.mp3` | folk | strummed guitar left, picked guitar right, upright bass, brushes and shaker |
| `6-latin-la-cucaracha.mp3` | latin, 3/4 | rumba-style nylon guitar, bass with anticipations, maracas, claves and congas |

Things I would check first: is any instrument too loud or too quiet (levels are set by measurement, not by
ear); does the intro make the tempo obvious; do the drum fills help or distract; is the ending clean.

## "Hear it played" over the new backing tracks (Part 3)

The sampled instrument exactly as the browser plays it, mixed over the backing track.

| File | Instrument |
|---|---|
| `hear-it-played-alto-sax-amazing-grace.mp3` | alto sax (University of Iowa recordings) |
| `hear-it-played-tenor-sax-danny-boy.mp3` | tenor sax (VCSL) |
| `hear-it-played-flute-greensleeves.mp3` | flute (University of Iowa) |
| `hear-it-played-trumpet-when-the-saints-go-marching-in.mp3` | trumpet (University of Iowa) |

Things I would check first: is the sax tone pleasant or too bright; do held notes sound natural (the loop
and the vibrato that fades in); is the instrument at a good level against the band.
